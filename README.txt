ALMANASA ALDHAKIA — Version 1 prototype
Open index.html in a browser or deploy the folder to Netlify.
This is a front-end demo, not a production backend or native Android/iOS app.
Requests are stored only in the same browser's localStorage; there is no secure login or remote transmission.
Prices are placeholders and require verification. Do not enter sensitive customer data.
Next steps: secure backend/database, authentication, staff roles, document uploads, notifications, real quotes, native app packaging, app-store accounts.
